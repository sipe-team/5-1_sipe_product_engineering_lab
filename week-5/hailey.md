# 5주차 미션 — PRD v2 업그레이드

> 4주차에 작성한 PRD를 셀프 리뷰하고, 벤치마킹으로 근거를 강화한 v2.

-----

## 벤치마킹

### 참고 서비스 1: Lingopie

**어떻게 풀었는지**

- 실제 TV 쇼, 영화, 애니메이션 클립으로 언어 학습
- 이중 자막(원어 + 모국어), 단어 클릭 시 즉시 번역, 레벨별 난이도 분류
- 레벨별 리뷰 모드: 초급은 Pop Quiz, 중급은 Word Master, 고급은 Sentence Wizard
- Short Stories 기능으로 짧은 이야기 + 원어민 나레이션 + 탭 번역 결합

**내 PRD에 반영할 점**

- “실제 현실 콘텐츠로 학습하면 이해도 체감이 강해진다”는 방향성을 시장 검증한 서비스 → Confidence 근거로 활용 (ICE Score Confidence 7점의 실제 레퍼런스)
- 레벨별로 다른 퀴즈 형식 제공 → V1 이후 이해도 측정 방식 다양화 참고 가능

**차별화할 점**

- Lingopie는 “학습 자체”가 영상 기반이지만, 내 PRD는 기존 Duolingo 레슨 구조를 유지하면서 “체감 테스트 모듈”로만 영상 활용 → 유료 구독 아닌 무료 기능으로 차별화
- Lingopie는 엔터테인먼트 콘텐츠 중심, Reality Check는 학습 성장 측정 중심

### 참고 서비스 2: Babbel

**어떻게 풀었는지**

- Babbel CEO Arne Schepker가 공식적으로 “우리 유저 대부분은 실제 대화를 하려고 언어를 배운다. 앱에서 높은 점수를 내려는 게 아니라”고 발언 — Duolingo의 게임 지표(XP, streak) 중심 접근과 정반대 방향
- Learning Activity 시각화로 학습을 구체적 실생활 스킬과 연결
- 완료된 레슨마다 “이제 할 수 있게 된 것”을 보여주는 achievement 기능 개발 중

**내 PRD에 반영할 점**

- 게임 지표(XP, streak)가 아닌 실생활 스킬 체감이 retention에 중요하다는 방향성이 이미 글로벌 레퍼런스로 존재 → 2주차에서 발견한 페인포인트의 업계 컨센서스 확인
- Happiness 지표 설정의 근거 강화 — “실력 체감”이 실제로 학습 만족도에 직결된다는 시장 검증

**차별화할 점**

- Babbel은 자체 플랫폼 내에서 스킬-실생활 매핑을 텍스트로 제공 (예: “이제 식당에서 주문할 수 있어요”)
- 내 PRD는 Babbel 한 걸음 더 나아가 **실제 영상으로 직접 확인**하는 구조. 텍스트 설명보다 영상이 체감 강도가 훨씬 높음

### 참고 서비스 3: TV5MONDE Apprendre

**어떻게 풀었는지**

- 프랑스 공영방송이 운영하는 무료 프랑스어 학습 플랫폼
- 실제 TV5MONDE 방송 뉴스 클립을 CEFR 레벨(A1~B2)에 맞게 큐레이션
- 클립마다 이해도 퀴즈 제공

**내 PRD에 반영할 점**

- MVP 콘텐츠 소스로 직접 활용 가능 — 학습자용으로 공개된 공공 콘텐츠라 라이선스 리스크 낮음
- “실제 방송 뉴스 + 레벨별 분류 + 이해도 퀴즈” 구조가 Reality Check MVP 설계와 거의 동일

**차별화할 점**

- TV5MONDE는 단독 학습 플랫폼이라 사용자가 따로 찾아가야 함
- 내 PRD는 Duolingo 안에서 레슨 흐름의 일부로 자연스럽게 노출 → 접근성과 컨텍스트가 핵심 차별점

## v1 → v2 변경 사항

### 셀프 리뷰에서 발견한 구멍

1. **“학습 동기 상실이 페인포인트”라는 근거가 감정적 추론 위주였음**
- 수정: 3주차 리서치에서 실제 장기 유저 인용문 5개를 구체적인 숫자/일수와 함께 명시 (1,500일, 628일, 588일 등). “감”이 아니라 “데이터 기반”으로 변경
1. **MVP 범위에 레벨별 분기 로직까지 포함되어 있었음 (실제로는 V1 수준)**
- 수정: MVP는 “A1~A2 단일 범위 + 5~10개 영상”으로 축소. 레벨별 분기는 V1으로 이동. “이것만 있어도 가설 검증 가능한가?” 기준 적용
1. **성공 지표가 “만족도 향상”으로 추상적이었음**
- 수정: Happiness를 구체적 측정 방식 2개로 분해 (앱스토어 부정 리뷰 비율 + 앱 내 설문 긍정 응답률). 현재(추정) 수치와 목표 수치를 “N% 상대 개선” 형태로 명시
1. **리스크 섹션에 Super 유료 전환 약화 리스크가 빠져있었음**
- 수정: “Reality Check가 ‘나 실력이 느네’ 체감을 주면 Super 결제 필요성이 약해질 수 있다”는 비즈니스 리스크 추가. 완화 방안으로 무료/유료 기능 경계 설계 포함

### 벤치마킹으로 강화한 부분

- **Lingopie 사례로 Confidence 점수 근거 강화** — ICE Score에서 Confidence 7점의 실제 시장 검증 레퍼런스 확보
- **Babbel CEO 발언으로 문제 정의 근거 강화** — “게임 지표보다 실생활 스킬이 중요하다”는 방향성이 업계 리딩 기업에서도 인정된다는 점을 배경 설명에 보강 가능
- **TV5MONDE로 MVP 실현 가능성 입증** — “공공 콘텐츠 5~10개로 시작한다”는 게 이론이 아닌 실제 가능한 계획임을 레퍼런스로 보여줌. Ease 점수 근거 강화

### 아직 남은 열린 질문

- 영상 콘텐츠 다양성 유지는 장기적으로 어떻게 할지 (MVP 이후 콘텐츠 파이프라인)
- 이해도 측정 방식의 학습 효과성 검증 (객관식이 최선인지)
- Reality Check → 복습 레슨 연결 UX 설계 (낮은 점수 시 어떻게 자연스럽게 학습으로 연결할지)
