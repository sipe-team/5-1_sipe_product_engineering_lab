# 3주차: 공개 데이터로 프로덕트 읽기

## 분석 대상

- **서비스**: 네이버 금융
- **분석한 기능**: 증권사 리서치 리포트 탐색 기능
- **서비스 유형**: B2C (포털 기반 금융 정보 서비스)

## 2주차에서 발견한 페인포인트

1. 원하는 종목 리포트를 찾기까지 탭 이동이 잦음
2. 제목만으로 리포트 품질/신선도 판단이 어려움
3. PDF/원문이 길어 핵심 파악에 시간이 걸림
4. 리포트 간 용어·전제 차이로 증권사 의견 비교 난이도 높음
5. 리포트 소비 후 실제 주문으로의 전환은 앱 간 이동이 필요해 전환 마찰 발생

---

## 공개 데이터 분석

### 사용한 소스

- 앱스토어(iOS) / 구글플레이 네이버 앱 리뷰
- 네이버 공식 기술 블로그(네이버 D2, 네이버 랩스)
- 네이버 IR 자료 및 분기 실적 발표
- 뉴스 (네이버페이증권, 네이버 금융 관련 기사)
- 채용 공고 분석

### 소스 선정 이유

네이버 금융은 독립 앱이 아닌 네이버 앱 내 서비스로, 스토어 리뷰에서 금융 기능만 추출하기 어렵다.
따라서 리뷰 키워드 검색("리포트", "증권", "리서치")과 함께 기술 블로그·IR 자료를 병행 분석했다.

## 앱스토어/플레이스토어 리뷰 분석

### 내 페인포인트와 겹치는 피드백

**페인포인트 1: 리포트 탐색 경로가 깊고 복잡**

> "종목 검색하고 리포트 탭 찾아가는 게 왜 이렇게 많이 클릭해야 하는지 모르겠음"
> "주식 화면에서 리서치 탭을 찾는 게 아직도 헷갈린다"

→ 종목 페이지 → 탭 이동 → 리포트 목록의 3단계 구조가 실사용에서 마찰로 인지되고 있음.

**페인포인트 2: PDF 원문 의존 구조**

> "요약 없이 PDF 열어야 하는 건 불편함. 증권사마다 포맷도 달라서 읽기 피곤"
> "목표주가만 보고 싶은데 전체 PDF 다운받아야 함"

→ 핵심 수치(목표주가·투자의견)를 파악하기까지 소요 비용이 사용자 인내심을 초과하는 케이스 존재.

**페인포인트 3: 비교 기능 부재**

> "같은 종목 두 증권사 의견이 완전 다른데 나란히 보는 기능이 없음"
> "BUY/HOLD 의견이 엇갈릴 때 근거 비교를 직접 해야 해서 번거로움"

→ 다수 증권사 의견이 동일 종목에 존재하지만 비교 레이어가 없어 사용자가 수작업으로 탭 전환.

### 추가로 발견한 페인포인트

**페인포인트 4: 오래된 리포트와 최신 리포트 구분 신호 부족**

> "날짜는 있는데 언제 기준 전망인지 헷갈림. 작년 리포트가 상단에 뜨는 경우도 있음"

→ 발행일 ≠ 전망 기준 시점의 불일치가 신뢰도 혼선을 유발.

**페인포인트 5: 리포트 소비 후 행동 연결 단절**

> "리포트 보고 사고 싶은데 바로 주문할 수 없어서 다른 앱으로 이동함"
> "관심종목에 추가하는 게 전부고, 알림은 설정이 복잡함"

→ 정보 소비 → 투자 행동 연결 고리가 약해 리텐션보다 이탈로 이어지는 흐름.

## 기업 공개 정보

### 기술 블로그 / 컨퍼런스

- 네이버 D2에서 "금융 데이터 파이프라인", "실시간 시세" 관련 기술 글 다수 존재
- 리포트 요약·AI 분석 관련 공개 발표는 아직 없음
  → 증권사 리포트 자동 요약은 네이버 내부에서도 미착수 또는 비공개 단계로 추정

### 뉴스 / IR 분석

- 2024년 네이버페이증권 출시로 **리포트 소비 → 투자 실행** 연결 의도 공식화
- 네이버페이증권은 MTS(모바일 트레이딩) 영역 진출 → 금융 정보 허브에서 거래 플랫폼으로 확장 전략 명확
- 2025년 기준 네이버 금융 MAU는 공개되지 않으나, 금융 섹션 트래픽은 검색 유입이 압도적 (네이버 IR 간접 언급)

### 채용 공고

- "금융 서비스 기획자", "AI 금융 데이터 분석" 포지션 지속 채용 중
- "증권 리포트 관련 ML/NLP 엔지니어" 포지션 미확인
  → AI 요약 기능이 아직 우선순위가 낮거나, 증권사 저작권 문제로 보류 중으로 추정

## HEART Framework 기반 판단

| 지표 | 평가 | 근거 |
|------|------|------|
| **Happiness** (만족도) | 중 | 정보 존재 자체는 유용하나 탐색 UX 피로도가 높아 만족도 분산 |
| **Engagement** (참여도) | 중하 | PDF 의존 구조로 깊은 읽기 행동 유도 어려움. 체류 시간 짧을 것으로 추정 |
| **Adoption** (채택률) | 중 | 포털 유입은 많으나 "리포트 탭까지 도달"하는 사용자는 소수 |
| **Retention** (재방문) | 중 | 경기·이벤트 기반 리텐션. 비시즌/횡보장에서 재방문 동기 약함 |
| **Task Success** (목표달성) | 중하 | 핵심 태스크(종목 리포트 빠르게 확인)의 완수 경로가 길고 마찰 많음 |

## 종합 판단

> **네이버 금융 리서치 리포트 탐색 기능은 "부분적 성공"이다.**

**성공한 부분:**
- 국내 최대 포털 기반으로 리포트 접근성 자체는 높음 (트래픽 확보)
- 증권사 리포트를 한 곳에서 볼 수 있는 유일한 무료 허브 포지션
- 네이버페이증권 출시로 정보→거래 연결 전략 방향은 올바름

**실패하고 있는 부분:**
- 리포트 탐색 UX가 "읽고 싶다"는 의도를 충족시키지 못함
- PDF 원문 의존 → 핵심 파악 비용 과다 → 중도 이탈 유발
- 증권사 간 비교·요약 기능 부재로 고관여 사용자의 니즈 미충족
- 리포트 소비 후 투자 행동으로의 전환 경로가 여전히 단절

**한계:**
- 증권사 리포트 저작권 이슈로 AI 요약 자동화에 제약 존재
- 개인화 추천 없이 최신순 나열만으로는 고관여 사용자의 반복 방문 유도 어려움

## 내가 PM이라면 다음에 뭘 할 것인가?

> 리포트 핵심 수치(목표주가·투자의견·상승여력) 카드형 요약 + 증권사 간 의견 비교 레이어 추가

가장 많은 사용자가 원하는 것은 "빠른 핵심 파악"이다.
PDF 없이도 목표주가·투자의견·상승여력을 한눈에 보여주는 카드 UI,
그리고 동일 종목 복수 증권사 의견을 나란히 비교하는 레이어가
탐색 마찰을 줄이고 체류 시간을 늘릴 핵심 개선이라고 판단한다.

**글 1:** [정성적 데이터 분석으로 사용자의 진짜 목소리를 읽어내는 법](https://epart.com/정성적-데이터-분석으로-사용자의-진짜-목소리를-읽/)

사용자의 불만 언어를 그대로 받아들이면 안 된다는 점이 인상적이었다.
"리포트가 불편하다"는 말은 단순 UI 문제가 아니라 "내가 원하는 정보를 원하는 시점에 얻지 못하는 구조적 실패"로 재해석해야 한다.
이번 분석에서 PDF 의존 문제를 "기능 부재"가 아니라 "정보 접근 비용 과다"로 프레이밍한 것도 이 관점에서 나왔다.

**글 2:** [무신사, 앱 새 단장 후 고객 경험 개선 — 무신사 뉴스룸](https://newsroom.musinsa.com/newsroom-menu/2024-1227)

UI/UX 개선만으로 상세 페이지 조회수 157% 상승, 구매 전환율 약 3배 증가라는 수치가 눈에 띄었다.
금융 리포트도 동일하다. 콘텐츠 자체의 품질보다 "얼마나 빠르게 핵심에 도달하게 만드느냐"가
사용자 행동을 바꾸는 결정적 변수다. 카드 요약 UI 하나가 체류 시간과 재방문율을 동시에 바꿀 수 있다.
