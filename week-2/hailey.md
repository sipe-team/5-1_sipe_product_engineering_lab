# 2주차 미션 — 사용자 플로우 역추적

## 분석 개요

### Why Duolingo?

- DAU에 집착하는 서비스로 유명 → Acquisition/Retention 설계가 교과서처럼 드러남
- 실제 유저로서 1차 경험 데이터 활용 가능
- Streak, Heart, League 등 각 기능의 비즈니스 목적이 명확하게 역추론 가능

### 분석 핵심 기능

**공부하기** — 앱 설치 → 학습 → 습관화 플로우

---

## 사용자 여정 (User Journey)

> 실제 사용 경험 기반: 프랑스어 학습, 지하철 출퇴근 중 사용, Super Duolingo 전환 유저

---

### STEP 1 · Referral → Acquisition
**친구 추천 → 앱 설치**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 친구에게 추천을 받고 앱 설치 |
| 감정 |  신뢰 기반 진입, 거부감 낮음 |
| 핵심 KPI | Referral conversion rate, Install rate |

**역산 분석**
- 신뢰 기반 유입은 초기 이탈률이 낮고 Activation 전환율도 높음
- 리그, 친구 퀘스트에 공을 들이는 이유 — Referral이 가장 품질 좋은 Acquisition 채널

---

### STEP 2 · Activation
**레벨 테스트 → 적절한 난이도 배치 → 첫 레슨**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 레벨 테스트 후 이미 아는 단계부터 시작, 첫 레슨 진행 |
| 감정 | 어렵지 않게 시작 → 아는 거 틀렸을 때 아쉬움 |
| 핵심 KPI | Session 1 completion rate |

**역산 분석**
- 완전 처음부터 시작하면 지루함 → 이탈. 레벨 테스트로 "이미 아는 것들"에서 시작하게 설계
- 알 것 같은 걸 틀리면 "내가 이걸 몰라?" 하는 아쉬움 → 다음 레슨으로 이어짐
- 완전히 모르는 걸 틀리는 것과 다른 심리 — 이것이 첫 세션 완료율을 높이는 핵심

---

### STEP 3 · Activation → Retention
**지하철 탑승 — 앱 열기 (습관화)**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 출퇴근 중 습관적으로 앱 오픈 |
| 감정 | 특별한 동기 없이 습관적으로 열음 |
| 핵심 KPI | DAU |

**역산 분석**
- 출퇴근 시간대를 타겟한 알림 설계 — 유저가 심심한 순간에 진입
- 목표: "지루할 때 자동으로 열리는 앱"이 되는 것

---

### STEP 4 · Retention
**복습 단계 자동 제시**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 열자마자 오늘의 복습이 자동으로 제시됨 |
| 감정 | 뭐 할지 고민할 필요 없음 |
| 핵심 KPI | Session start rate |

**역산 분석**
- "뭐 할까?" 고민 자체가 이탈 원인
- 알고리즘이 대신 결정 → 결정 피로 제거 → 세션 시작률 상승
- 선택지를 없애는 것이 곧 retention 설계

---

### STEP 5 · Retention
**레슨 진행 — 반복 패턴 + 미니게임 세션 믹스**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 5개 레슨 진행. 같은 패턴 반복 중간에 단어 매칭, 듣기 등 빠른 세션 등장 |
| 감정 | 반복 패턴은 지루함 → 빠른 세션에서 각성 |
| 핵심 KPI | Session completion rate |

**역산 분석**
- 단조로움이 이탈을 부름 → 세션 유형을 믹스해 체감 속도를 높임
- 몇 초 안에 끝나는 빠른 세션이 "다음 것도 해볼까?" 하는 클릭을 유도

---

### STEP 6 · Revenue
**오답 → 하트 소멸 → 답답함 → 결제**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 오답이 쌓여 하트가 다 소멸 → 학습 중단 → Super 결제 |
| 감정 | 극도로 답답함 → 결제로 해결 |
| 핵심 KPI | Free-to-paid conversion rate, ARPU |

**역산 분석**
- 하트는 "학습 방해 도구"가 아니라 **전환 트리거**
- 가장 몰입된 순간에 마찰을 삽입 → 학습을 멈추고 싶지 않은 상태에서 결제 결정
- 짜증이라는 감정 자체가 Revenue 설계의 핵심

> 실제 경험: "너무 답답해서 그냥 결제했어"

---

### STEP 7 · Retention
**레슨 5개 완료 → XP 획득 → Streak 업데이트**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 레슨 완료 후 XP 획득, Streak 숫자 상승 확인 |
| 감정 | 숫자가 높아질수록 포기하지 못하는 감각 |
| 핵심 KPI | D30 Retention, Average streak length |

**역산 분석**
- 손실 회피(Loss Aversion) 심리 설계 — Streak이 길어질수록 "끊으면 손해"라는 감각이 강해짐
- 학습 동기가 아니라 손실 회피가 재방문을 만드는 구조
- 사용자는 배우기 위해서가 아니라 Streak을 지키기 위해 앱을 열게 됨

> 실제 경험: "streak은 숫자가 높을수록 포기하지 못하겠더라구"

---

### STEP 8 · Retention + Referral
**리그 순위 확인 (선택적)**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 주간 리그 순위 확인, 강등 위협 또는 상위권 유지 |
| 감정 | 강등 위협 or 상위권 쾌감 |
| 핵심 KPI | Weekly active rate |

**역산 분석**
- 강등 위협이 다음 주 접속을 보장 — Streak이 개인 게임이라면 리그는 멀티플레이어 게임
- 사회적 압력이 추가되면서 retention 강도가 높아짐
- 상위 입상 시 보상(보석)이 Referral로도 연결

---

### LOOP · 내일 또
**앱 종료 → 알림 → 다시 열기**

| 항목 | 내용 |
|------|------|
| 사용자 행동 | 앱 종료 후 다음날 알림 수신 → 다시 진입 |
| 감정 | Streak 지키려고 내일도 열어야 함 |
| 핵심 KPI | Habit loop 완성 |

**역산 분석**
- Cue(알림) → Routine(레슨) → Reward(XP/Streak) 루프 완성
- 학습이 목적이 아니라 루틴 자체가 목적이 됨
- 최종 상태: "오늘 뭔가 안 한 것 같다"는 느낌이 들 때 자동으로 앱을 여는 것

---

## AARRR 프레임워크 요약

| 단계 | 핵심 기능 | 비즈니스 목적 |
|------|----------|--------------|
| **Acquisition** | 친구 추천 / 밈 바이럴 | 신뢰 기반 고품질 유입 |
| **Activation** | 레벨 테스트 + 첫 레슨 설계 | 첫 세션 완료율 극대화 |
| **Retention** | Streak / 리그 / 알림 / 복습 자동화 | 손실 회피 + 습관 루프 |
| **Revenue** | Heart 시스템 → Super 전환 | 몰입 순간에 마찰 삽입 |
| **Referral** | 리그 / 친구 퀘스트 / 스코어 공유 | 기존 유저가 신규 유입 채널 |

---

## 핵심 인사이트

### 1. Duolingo는 학습 앱이 아니라 습관 설계 앱이다
사용자가 앱을 여는 이유가 "프랑스어를 배우고 싶어서"에서 "Streak을 지키기 위해서"로 이동한다. 이 전환이 Duolingo가 DAU를 유지하는 핵심 구조.

### 2. 하트 시스템은 방해가 아니라 설계다
가장 몰입된 순간에 마찰을 삽입하는 것이 전환율을 높이는 방법. "짜증난다"는 감정 자체가 결제 트리거.

### 3. Referral이 가장 강력한 Acquisition이다
친구 추천으로 유입된 사용자는 광고 유입보다 초기 이탈률이 낮다. 리그/친구 퀘스트가 단순한 소셜 기능이 아니라 Acquisition 채널인 이유.

### 4. "아는 것을 트리거해서 틀리면 아쉽게 만든다"
완전 모르는 것을 틀리면 포기하지만, 알 것 같은 것을 틀리면 다시 하고 싶어진다. 레벨 테스트와 초기 레슨 설계의 핵심 심리.
