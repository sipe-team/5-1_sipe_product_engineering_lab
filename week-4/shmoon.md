# 4주차: PRD — 네이버 금융 리서치 리포트 "핵심 요약 카드 + 의견 비교" 개선

> **한 줄 요약**: 증권사 리포트를 PDF 없이 30초 안에 핵심을 파악하고, 동일 종목의 복수 증권사 의견을 나란히 비교할 수 있도록 카드형 요약 레이어를 추가한다.

## 분석 대상

- **서비스**: 네이버 금융
- **선정한 페인포인트** (3주차에서 검증):
  - PDF 원문 의존 구조로 핵심 파악 비용 과다 (앱 리뷰 다수에서 반복 확인)
  - 증권사 간 의견 비교 기능 부재로 고관여 사용자의 핵심 니즈 미충족

---

## 1. 배경 및 문제 정의 (Why)

### 문제 상황

네이버 금융에서 증권사 리포트를 탐색하는 사용자는 **"이 종목을 사야 하는가, 말아야 하는가"** 라는 명확한 질문을 가지고 진입한다. 이 질문에 답하기 위해 필요한 정보는 사실 단순하다: **목표주가, 투자의견(BUY/HOLD/SELL), 상승여력, 핵심 논거 1~2줄**.

그러나 현재 네이버 금융 리포트 탐색 구조는 이를 제공하지 못한다.

1. **리포트 목록**에서 보이는 것은 제목, 증권사명, 발행일뿐이다.
2. 핵심 수치를 확인하려면 **PDF를 열어야 한다**. 증권사마다 포맷이 달라 목표주가가 표지에 있기도, 본문 중간에 있기도 하다.
3. 같은 종목에 대해 A증권사는 BUY(목표주가 100,000원), B증권사는 HOLD(목표주가 82,000원)일 때, 두 의견을 **나란히 비교하는 기능이 없다**.

결과: 사용자는 PDF를 2~3개 열어서 직접 수치를 메모하고 비교해야 한다. 이 과정에서 소요 비용이 인내심을 초과하면 중도 이탈한다.

### 영향받는 사용자

- **핵심 타겟**: 투자 전 리포트를 "근거 확인" 목적으로 소비하는 개인 투자자 (소위 "확인형 투자자")
- **추정 규모**: 네이버 금융 리포트 탭 방문자 중 PDF를 한 개 이상 열어본 사용자. 리포트 탭 진입 후 실제 PDF 클릭률은 업계 유사 서비스 기준 20~30%로 추정 → 나머지 70~80%는 목록 탐색 후 이탈
- **세그먼트 특성**: 투자 경험 1년 이상, 주 1회 이상 시세 확인, 결정 전 "근거 수집" 행동 패턴 보유

### 근거

**앱스토어/플레이스토어 리뷰 분석 (3주차)**:
- "요약 없이 PDF 열어야 하는 건 불편함. 증권사마다 포맷도 달라서 읽기 피곤"
- "목표주가만 보고 싶은데 전체 PDF 다운받아야 함"
- "같은 종목 두 증권사 의견이 완전 다른데 나란히 보는 기능이 없음"
- "BUY/HOLD 의견이 엇갈릴 때 근거 비교를 직접 해야 해서 번거로움"

**기업 공개 정보 분석 (3주차)**:
- 네이버페이증권 출시(2024)로 "정보 소비 → 투자 실행" 연결 의도 공식화
- AI 요약 관련 공개 기술 발표 없음 → 요약 기능은 아직 미착수 또는 비공개 단계
- "금융 서비스 기획자", "AI 금융 데이터 분석" 채용 지속 → 관련 투자 방향 확인

**구조적 근거**:
- 증권사 리포트는 정형화된 구조(커버 페이지에 목표주가·투자의견 명시)를 가짐 → 파싱 가능성 높음
- 리포트 핵심 수치(목표주가·투자의견·상승여력)는 저작권 이슈가 낮은 사실 정보 영역

### 방치하면 생기는 비즈니스 영향

네이버 금융의 리포트 탐색 기능의 가치는 **"사용자가 정보를 얻고, 다시 네이버 안에서 행동(관심종목 등록, 네이버페이증권 이동)하게 만드는 것"** 이다.

현재 구조에서는:
- PDF 탐색 비용 과다 → **중도 이탈 → 다른 플랫폼(증권사 앱, 유료 서비스)으로 이탈**
- 비교 기능 부재 → **의사결정이 필요한 고관여 순간에 네이버를 떠남**
- 이탈 이후 네이버페이증권으로의 전환 기회 소멸

장기적으로 리포트 탐색에서의 이탈은 네이버페이증권의 거래 전환율과 직결된다. 리포트 기능이 "정보 신뢰 허브"로 자리잡지 못하면, 경쟁 플랫폼(증권사 HTS, 토스증권 리서치 탭)에 고관여 사용자를 뺏긴다.

## 2. 목표와 성공 지표 (What + KPI)

### 목표 (Goal)

> 리포트를 탐색하는 사용자가 PDF를 열지 않고도 30초 안에 핵심 판단 근거를 확보하고, 동일 종목 복수 증권사 의견을 한 화면에서 비교할 수 있게 한다.

### 성공 지표 (KPI)

| 지표 | 카테고리 | 현재(추정) | 목표 |
|------|---------|-----------|------|
| 리포트 탭 진입 후 PDF 미클릭 이탈률 | Task Success | 70~80% | 50% 이하 |
| 리포트 탭 평균 체류 시간 | Engagement | 45초(추정) | 90초 이상 |
| 리포트 탭 → 관심종목 등록 전환율 | Retention | 측정 미정 | 기준 대비 +30% |
| 리포트 기능 관련 부정 리뷰 비율 | Happiness | 리뷰 내 반복 언급 | 언급 빈도 50% 감소 |

**핵심 지표**: **"리포트 탭 진입 후 PDF 미클릭 이탈률 70~80% → 50% 이하"**

이게 핵심인 이유: PDF를 열지 않고 이탈하는 것이 "핵심 정보를 얻지 못했다"는 직접 신호다. 이 이탈률을 낮추는 것이 체류 시간, 전환율, 재방문 모든 지표의 선행 조건이다.

## 3. 사용자 경험 변화 (Before → After)

### Before (현재)

박민준(32세, 직장인 투자자)은 보유 중인 A종목 실적 발표 다음 날 네이버에서 종목명을 검색한다. 종목 페이지에서 "리서치" 탭을 찾아 이동한다. 오늘 발행된 리포트가 3개 있다.

제목을 읽어보면 비슷하다. 어느 게 좋은 의견인지 제목만으론 모른다. 첫 번째 리포트를 클릭한다. PDF가 열린다. 4페이지짜리 PDF에서 목표주가를 찾아야 한다. 표지에 있다. 목표주가 95,000원, BUY.

두 번째 리포트를 클릭한다. 또 PDF다. 이건 6페이지다. 스크롤을 내린다. 2페이지에 목표주가 78,000원, HOLD. "왜 의견이 다르지?" 근거를 비교하려면 두 PDF를 번갈아 봐야 한다.

세 번째 리포트도 클릭하려다 멈춘다. "시간이 너무 걸린다." 박민준은 앱을 닫고 유튜브에서 해당 종목 리뷰 영상을 찾아본다.

### After (개선 후)

박민준은 A종목 페이지의 리서치 탭에 들어온다. 오늘 발행된 리포트 3개가 목록에 표시된다. 각 리포트 카드에는 이미 핵심 정보가 표시되어 있다.

```
[NH투자증권]  BUY  목표주가 95,000원 (+18%)  "실적 서프라이즈, 연간 가이던스 상향"
[한국투자증권] HOLD  목표주가 78,000원 (-3%)   "밸류에이션 부담, 단기 모멘텀 제한적"
[삼성증권]    BUY  목표주가 91,000원 (+13%)  "하반기 실적 회복 기대"
```

박민준은 PDF를 열지 않고 30초 만에 상황을 파악한다. "BUY 2, HOLD 1이고, 목표주가 범위는 78,000~95,000원이구나."

"왜 한국투자증권만 HOLD인가?" 가 궁금하다. 카드를 탭하면 핵심 논거 2~3줄이 펼쳐진다. 밸류에이션 배수와 단기 이익 추정치 하향 이유가 간략히 나온다. PDF 원문 링크도 하단에 있다.

박민준은 이 정보를 바탕으로 관심종목에 알림을 설정하고, 네이버페이증권으로 이동해 매수 여부를 결정한다. 오늘 리포트 3개를 다 읽었는데 5분도 안 걸렸다.

## 4. 솔루션 접근법 (How - 개괄)

### 접근 방식

> **"리포트 목록 카드에 핵심 수치(투자의견·목표주가·상승여력·핵심 논거)를 자동 파싱하여 표시하고, 동일 종목 복수 리포트를 비교 레이어로 제공한다."**

### 핵심 아이디어

1. **리포트 카드 요약 표시**: 목록 카드에 투자의견(BUY/HOLD/SELL), 목표주가, 현재가 대비 상승여력(%)을 자동 파싱·표시. 증권사 리포트 커버 페이지는 정형화된 구조를 가지므로 규칙 기반 파싱으로 시작 가능.
2. **핵심 논거 1~2줄 요약**: 카드 클릭 시 펼쳐지는 논거 요약. 초기에는 증권사 제공 요약문(요약란) 활용, 이후 NLP 기반 자동 요약 적용.
3. **동일 종목 의견 비교 레이어**: 종목 리서치 탭 상단에 "증권사 의견 요약" 테이블 고정 표시. 최신 리포트 기준으로 증권사별 투자의견·목표주가를 한눈에 비교.

### 기술적/디자인적 고려사항

- **파싱 방식**: 증권사별 PDF 포맷에 대한 규칙 기반(Rule-based) 파서 우선 구현. 80% 이상 커버 가능한 상위 증권사(미래에셋·NH·KB·삼성·한투 등 10개사) 우선 대상.
- **저작권 고려**: 목표주가·투자의견은 사실 정보로 저작권 주장이 어려움. 핵심 논거 요약은 증권사 제공 요약문(이미 공개된 텍스트) 사용 → 법무 검토 필요.
- **파싱 실패 처리**: 파싱 실패 시 카드에 "-" 표시 + "원문 보기" 링크로 폴백.
- **데이터 업데이트 주기**: 리포트 발행 직후 파싱 파이프라인 트리거 → 목록 노출 시점에 수치 이미 표시.

## 5. ICE Score

이번 문제를 해결할 수 있는 후보 아이디어를 4개 나열하고, ICE 기준으로 우선순위를 비교한다.

| 후보 아이디어 | 설명 | Impact | Confidence | Ease | ICE Score | 판단 |
|------|------|------:|------:|------:|------:|------|
| A. 리포트 카드 핵심 수치 파싱 표시 | 목록 카드에 투자의견·목표주가·상승여력 자동 파싱 표시 | 9 | 7 | 6 | 378 | 채택 |
| B. 증권사 의견 비교 테이블 | 종목 탭 상단에 증권사별 의견을 나란히 보여주는 비교 레이어 | 8 | 7 | 5 | 280 | V1 후보 |
| C. AI 기반 리포트 전문 요약 | NLP 모델로 PDF 원문 전체를 3줄로 요약 | 8 | 4 | 3 | 96 | 보류 |
| D. 사용자 직접 메모/하이라이트 | 사용자가 PDF 읽으면서 직접 핵심 표시 저장 | 5 | 6 | 4 | 120 | 보류 |

### 선택한 아이디어

**A안 (카드 핵심 수치 파싱 표시)** 을 MVP로 채택한다.

Impact가 가장 높고, 증권사 리포트의 정형화된 구조 덕분에 Confidence도 충분하다. 가장 많은 사용자가 겪는 "핵심 파악 비용 과다" 문제를 PDF 없이 해결하며, 기술 구현도 규칙 기반 파싱으로 시작 가능해 Ease도 현실적이다.

B안은 Impact와 Confidence 모두 준수하지만, A안의 파싱 데이터가 있어야 의미있는 비교 테이블을 만들 수 있다. A안 이후 자연스러운 V1 작업이다.

### 선택하지 않은 아이디어

- **C안**: Impact는 높지만 Confidence가 낮다. 증권사 리포트 저작권 이슈 + NLP 요약 품질 불안정 + 오요약 시 투자 판단 오류 리스크. 기술 성숙도가 올라오면 V2 이후 검토.
- **D안**: 사용자 부담을 오히려 증가시키는 방향. 핵심 파악 비용을 낮추는 게 목표인데, D안은 사용자가 직접 그 비용을 부담하게 만든다. 방향이 맞지 않음.

## 6. 범위와 우선순위 (Scope)

앞선 ICE Score에서 선택한 **A안: 리포트 카드 핵심 수치 파싱 표시** 를 기준으로 범위를 나눈다.

| 범위 | 내용 |
|------|------|
| **MVP** (이번에 만들 것) | 상위 10개 증권사 리포트 PDF 규칙 기반 파싱 → 목록 카드에 투자의견·목표주가·상승여력 표시. 파싱 실패 시 "-" + 원문 링크 폴백 |
| **V1** (다음 스프린트) | 종목 리서치 탭 상단 "증권사 의견 비교 테이블" 추가 (B안). 핵심 논거 1~2줄 카드 펼침 표시 |
| **V2** (나중에) | 증권사 커버리지 확대 + 파싱 정확도 개선 (규칙 기반 → ML 기반 전환). 목표주가 컨센서스(평균·범위) 자동 계산 표시 |
| **Out of Scope** | AI 전문 요약(C안), 사용자 메모/하이라이트(D안), 리포트 추천 알고리즘 개인화, PDF 뷰어 내부 UI 개편 |

**MVP를 작게 쪼갠 이유**: 파싱 파이프라인 + 카드 UI 변경만으로 "PDF 없이 핵심 파악" 가설을 검증할 수 있다. 비교 레이어(B안)는 A안 데이터가 쌓인 후 더 가치있으므로 V1으로 미룬다.

## 7. 리스크와 대안 (Risks)

### 리스크 1: 증권사별 PDF 포맷 다양성으로 파싱 정확도 저하

- **시나리오**: 증권사마다 목표주가 위치, 표기 방식(숫자, 한글 혼재)이 달라 파싱 실패율이 예상보다 높을 수 있음. 잘못 파싱된 목표주가가 카드에 노출되면 사용자 투자 판단에 오류 유발.
- **완화**:
  1. 배포 전 10개 증권사 × 최근 50개 리포트로 파싱 정확도 사전 검증. 95% 이상만 MVP 대상에 포함.
  2. 파싱 결과에 "증권사 공식 리포트 원문 기준" 안내 문구 추가 → 책임 소재 명확화.
  3. 파싱 실패율 대시보드 모니터링 → 1주일 내 이상 감지 시 해당 증권사 카드 롤백.

### 리스크 2: 증권사 저작권 이슈 제기

- **시나리오**: 일부 증권사가 목표주가·논거 요약 표시에 대해 저작권 또는 데이터 사용 이의를 제기할 수 있음.
- **완화**:
  1. MVP에서는 목표주가·투자의견(사실 정보)만 표시 → 저작권 주장 가능성 최소화.
  2. 법무팀 사전 검토 후 증권사 약관·데이터 제공 계약 확인.
  3. 장기적으로는 증권사와 데이터 제공 파트너십 체결 방향으로 전환 (네이버의 협상력 활용).

### 리스크 3: 사용자가 카드 수치만 보고 PDF를 아예 읽지 않게 됨

- **시나리오**: 요약 수치만 보고 투자 결정 → 맥락 없는 판단으로 손실 → 네이버 금융에 대한 신뢰도 하락.
- **완화**:
  1. 카드 하단에 "투자 결정 전 원문 확인을 권장합니다" 문구 + 원문 링크 항상 노출.
  2. 요약은 "탐색 보조 도구"임을 UI 언어로 명확히 포지셔닝.

## 8. 열린 질문 (Open Questions)

- **파싱 대상 증권사 범위**: 상위 10개사부터 시작하면 전체 리포트의 몇 %를 커버할 수 있는가? 80% 이상이면 MVP로 충분한가?
- **목표주가 이력 표시**: 같은 증권사가 이전 리포트에서 목표주가를 낮춘 경우, 이력(화살표 표시)을 함께 보여주는 것이 사용자에게 더 유용한가? → 체류 시간 vs 정보 과부하 트레이드오프 검토 필요
- **비교 테이블 기준 시점**: 증권사별 가장 최신 리포트를 비교 기준으로 삼을 때, "3개월 전 BUY"와 "어제 HOLD"를 동등하게 나열해도 괜찮은가? 유효 기간 기준 정의 필요.
- **네이버페이증권과의 연동 범위**: 비교 테이블 또는 카드에서 바로 "매수" 버튼을 연결하는 것이 이번 MVP에 포함되어야 하는가, 아니면 별도 PRD로 분리해야 하는가?
- **증권사와의 데이터 파트너십 가능성**: 파싱 대신 증권사가 구조화된 데이터(JSON 등)를 직접 제공하는 방식이 현실적인가? → BD/파트너십 팀과 논의 필요.
